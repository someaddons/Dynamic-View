# Dynamic View

[![CurseForge Downloads](https://cf.way2muchnoise.eu/full_366140_downloads.svg)][curseforge] [![Minecraft Versions](https://cf.way2muchnoise.eu/versions/366140.svg)][curseforge] [![Download on CurseForge](https://img.shields.io/badge/Download-CurseForge-F16436?logo=curseforge&logoColor=white)][curseforge]

Dynamic View is a lightweight server utility mod to help balancing lag(tps) and chunk view and simulation distance.

The mod balances view and simulation distance around a long-time average tps which fits the servers performance, allowing optimal view and simulation distance for each player
count.

## Installation

1. Install the required mod loader.
2. Download the mod from the official CurseForge page.
3. Place the `.jar` file in your `mods` folder.

> This mod is officially distributed only through CurseForge. Downloads from other websites may be outdated, modified, or unsafe.
